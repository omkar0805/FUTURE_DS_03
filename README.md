# 📊 Marketing Funnel Analysis Dashboard

A comprehensive **Power BI Marketing Funnel Dashboard** built to analyze customer behavior across the entire purchasing journey—from website visits to completed purchases. This project provides actionable business insights into campaign performance, customer conversion, revenue generation, and marketing effectiveness.

---

## 📌 Project Overview

Marketing teams invest significantly in attracting customers, but understanding where users drop off in the sales funnel is essential for improving conversions and maximizing ROI.

This dashboard visualizes every stage of the marketing funnel and helps identify:

- Customer acquisition performance
- Product engagement
- Cart abandonment
- Checkout completion
- Revenue generation
- Campaign effectiveness
- Channel-wise performance
- Device and regional conversion trends

---

## 🎯 Business Objective

The primary objective of this project is to:

- Analyze customer behavior across the marketing funnel
- Measure conversion rates at each stage
- Evaluate campaign performance
- Identify high-performing acquisition channels
- Track monthly revenue trends
- Discover opportunities to improve customer conversion and revenue

## 📈 Dashboard KPIs

The dashboard tracks the following business metrics:

| KPI | Description |
|------|-------------|
| Total Sessions | Total website visits |
| Product Views | Number of products viewed |
| Added to Cart | Customers adding products to cart |
| Checkout Started | Customers initiating checkout |
| Purchases | Completed orders |
| Average Order Value | Average revenue per order |

## 🔍 Key Insights

- Discount campaigns generated the highest revenue.
- Paid Ads delivered the largest number of purchases.
- Mobile users contributed the majority of conversions.
- Revenue remained relatively stable across the analyzed months.
- Significant customer drop-off occurs between Product Views and Added to Cart.
- Checkout optimization can further improve purchase conversion.

---

## 💡 Business Recommendations

- Increase investment in high-performing campaigns.
- Improve product pages to increase Add-to-Cart rates.
- Implement abandoned cart reminder campaigns.
- Optimize checkout flow to reduce friction.
- Enhance desktop user experience.
- Continuously monitor campaign ROI and conversion metrics.
